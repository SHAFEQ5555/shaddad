# assets

ضع هنا ملفات الصور المستخدمة في الموقع:

- `hero.jpg` — صورتك السينمائية التي تظهر في الهيرو (خلفية داكنة/سوداء تعطي أفضل نتيجة).
- `shafeq-logo.png` — (اختياري) صورة شعار SHAFEQ الأصلي، لتفعيلها بدّل السطر النصي بسطر الصورة في `index.html`.

## طريقة إضافة صورتك
1. احفظ صورتك باسم `hero.jpg` داخل هذا المجلد.
2. أعد تحميل الصفحة — ستظهر الصورة في الهيرو تلقائياً.

مقاس مقترح: 1600×2000 بكسل أو أكبر، بجودة عالية.
